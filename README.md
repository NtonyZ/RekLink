# Портал продаж рекламного инвентаря ФОРУС

Прототип сайта-витрины для продажи рекламных мест ЧПУП «ФОРУСультра»: скроллеры и LED-экраны в Витебске и Полоцке, видеопанели в торговых сетях Минска, Могилёва, Гомеля и Новополоцка. Сайт разворачивается на домене **forus.by**; имя репозитория `RekLink` осталось от рабочего названия проекта и на витрине больше не используется.

Сайт позволяет клиенту самостоятельно, без звонка менеджеру:
- смотреть каталог рекламных конструкций (скроллеры, медиа-скроллеры, LED-экраны, indoor-видеопанели) с ценой, форматом, реальными фото и охватом;
- искать свободные места на интерактивной карте с фильтром по бюджету;
- подбирать площадки под бюджет в калькуляторе — или оставить заявку «Подобрать за меня» без выбора конкретных мест;
- собирать медиаплан, видеть предупреждение, если выбранный старт уже не укладывается в сроки подготовки, и оформлять заявку;
- заказать ролик под конкретный экран и сопровождение кампании — бриф на странице услуг;
- смотреть требования к макетам, порядок работы и справочную информацию по сбору за размещение рекламы;
- в личном кабинете — раскрывать заказ в карточку с составом, документами и историей статуса, продлевать или повторять размещение.

## Структура

| Страница | Назначение |
|---|---|
| `index.html` | Главная: форматы, свободные места, как это работает |
| `catalog.html` | Каталог конструкций со списком, картой, фильтрами и реальными фото |
| `map.html` | Карта размещений |
| `calculator.html` | Калькулятор бюджета кампании + заявка «Подобрать за меня» |
| `structure.html` | Карточка конкретной конструкции/стороны: галерея, описание расположения, панорама «Яндекс», календарь занятости, проверка сроков |
| `mediaplan.html` | Медиаплан и оформление заявки |
| `formats.html` | Форматы рекламы и тарифы |
| `services.html` | Видеопродакшн и сопровождение кампаний, бриф на ролик |
| `info.html` | Требования к материалам, оферта, порядок работы, сбор за рекламу |
| `cabinet.html` | Иллюстративный личный кабинет: заказы (в т.ч. только что оформленные), документы, фотоотчёты, профиль |
| `admin.html` | Иллюстративная адресная программа для сотрудников: сводный календарь занятости, простаивающие позиции (ссылка — в подвале сайта) |
| `register.html` | Регистрация и вход по номеру телефона с кодом подтверждения, профиль клиента |

На страницах подбора выводится сквозная полоса шагов «1 Выбор площадок → 2 Медиаплан → 3 Заявка». Доступ по регистрации включается флагом `RL.auth.required` в `assets/js/data.js` (по умолчанию выключен) и закрывает только медиаплан и личный кабинет — каталог, форматы и цены остаются открытыми для индексации поисковыми системами.

В каталоге, калькуляторе и мастере подбора участвуют все шесть городов присутствия: скроллеры и LED-экраны в Витебске и Полоцке, видеопанели в торговых сетях Минска, Могилёва, Гомеля и Новополоцка. Список городов считается из данных (`RL.cities`), а не вписан в тексты; `RL.outdoorCities` используется там, где речь только о собственных конструкциях (адресная программа).

Документы для внешнего мира. Оферта и политика: исходники `docs/publichnaya-oferta.md` и `docs/politika-personalnye-dannye.md`, из каждого собираются текст на странице «Информация» и файл Word для согласования; редактируется только markdown, поэтому редакции не расходятся. Коммерческое предложение: единственный источник — `docs/kp-print.html`, из него печатается `Коммерческое_предложение_forus_by.pdf` через headless Edge (дизайн повторяет образец заказчика). Word-версии у предложения нет намеренно — два источника одного документа неизбежно разъезжаются.

Планирование работ: `Задачи_Битрикс24_портал.xlsx` — 42 задачи по сотрудникам со сроками и критерием «что считать выполненным» (столбцы совпадают с полями Битрикс24); `Дорожная_карта_forus_by.docx` — те же данные в виде контрольных дат и графика по месяцам. Оба документа строятся из одного источника, поэтому не расходятся между собой.

Данные по конструкциям, форматам, ценам, услугам видеопродакшна и сети indoor-партнёров хранятся в `assets/js/data.js`; общая логика — в `assets/js/*.js`; стили — в `assets/css/base.css`. Реальные фотографии площадок (`assets/img/structures/`), описания расположения и ссылки на панорамы «Яндекс» (`assets/js/locations.js`) взяты из адресной презентации ФОРУС «Скроллеры, ситилайты, медиа-скроллеры» (2026); там, где фото нет, используется цветная заглушка формата. Состав услуг на `services.html` берётся из `RL.services`; цены видеопродакшна на витрине намеренно не публикуются — смета считается после брифа.

## Запуск локально

Статический сайт без сборки. Поднять локальный сервер (Windows/PowerShell):

```powershell
./serve.ps1
```

По умолчанию сайт откроется на `http://localhost:8791`.

## Статус

Демонстрационный прототип: заявки не уходят на реальный сервер, тексты публичной оферты и политики обработки персональных данных подготовлены и ждут утверждения, оплата и загрузка файлов в личном кабинете не реализованы. Страница `admin.html` — иллюстрация раздела «Адресная программа» из ТЗ: занятость и наименования клиентов сгенерированы детерминированно, реального логина, редактирования и выгрузки в Excel нет.
