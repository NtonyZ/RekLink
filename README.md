# RekLink

RekLink.by — прототип сайта-витрины для продажи рекламных мест оператора наружной и indoor-рекламы (ФОРУС) в Витебске и Полоцке.

Сайт позволяет клиенту самостоятельно, без звонка менеджеру:
- смотреть каталог рекламных конструкций (скроллеры, медиа-постеры, LED-экраны, indoor-видеопанели) с ценой, форматом и охватом;
- искать свободные места на интерактивной карте;
- подбирать площадки под бюджет в калькуляторе;
- собирать медиаплан и оформлять заявку на размещение;
- смотреть требования к макетам, порядок работы и справочную информацию по сбору за размещение рекламы.

## Структура

| Страница | Назначение |
|---|---|
| `index.html` | Главная: форматы, свободные места, как это работает |
| `catalog.html` | Каталог конструкций со списком, картой и фильтрами |
| `map.html` | Карта размещений |
| `calculator.html` | Калькулятор бюджета кампании |
| `structure.html` | Карточка конкретной конструкции/стороны |
| `mediaplan.html` | Медиаплан и оформление заявки |
| `formats.html` | Форматы рекламы и тарифы |
| `info.html` | Требования к материалам, оферта, порядок работы, сбор за рекламу |
| `cabinet.html` | Иллюстративный личный кабинет (демо-данные) |

Данные по конструкциям, форматам, ценам и сети indoor-партнёров хранятся в `assets/js/data.js`; общая логика — в `assets/js/*.js`; стили — в `assets/css/base.css`.

## Запуск локально

Статический сайт без сборки. Поднять локальный сервер (Windows/PowerShell):

```powershell
./serve.ps1
```

По умолчанию сайт откроется на `http://localhost:8791`.

## Статус

Демонстрационный прототип: заявки не уходят на реальный сервер, оферта и политика обработки персональных данных — черновики для сценария, оплата и загрузка файлов в личном кабинете не реализованы.
